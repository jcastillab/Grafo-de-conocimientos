# Grafo de conocimiento

Este archivo contiene instrucciones generales, no inventario de proyectos.
Para generar una vista desde una carpeta base, sigue `README.md` y ejecuta el
generador indicando esa carpeta. Cada ejecución descubre sus subcarpetas desde
cero; solo usa metadatos externos si se indican explícitamente.

Las fichas de proyecto y relaciones, si se necesitan, deben describir
únicamente la carpeta base elegida por la persona usuaria y evidencia verificada
allí. No copies inventarios ni relaciones de otras ubicaciones.
